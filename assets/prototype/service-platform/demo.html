怎么看这份 Demo
  1. 切上面的页签换页面；预览区内部可以滚动，看到的是页面真实渲染结果（不是截图）。
  2. 每页左侧是页面索引（TOC），中间是 macOS 窗口形态的原型，右侧「功能概览」是该 section 的 PRD 旁注；把鼠标移到旁注条目上，对应组件会高亮（评审脚手架）。
  3. 工作台页里可以真的点：会话卡切换（草稿与实体 Chip 按会话恢复）、右侧四模块切换（会话摘要 / 知识搜索 / AI 助手 / 顾客·订单，同一时间只展示一个，不再堆叠）、面板折叠、「插入输入框」直接把草稿写入输入框（空框填入、有内容时光标处插入，不弹窗）、发送按钮的防重复状态、右侧面板内联展开的转人工表单。点「搜知识 / AI 回复」或会话头部的实体 Chip 会自动跳到对应模块。全程没有任何弹窗与遮罩，对话区始终可见可操作。
  4. 右侧「会话摘要」可按过去 48 小时 / 过去 7 天切换范围：48 小时看当前窗口的事实与已答复，7 天看重复进线与诉求演变；内容按「结论式诉求 → 情绪与期望 → 关键事实 → 已答复 → 仍缺什么 → 顾客原话要点」组织，坐席不需要回滚长消息。
  5. 「知识搜索」模块在结果之上新增带编号引用的 AI 总结：只概括本次命中的知识、可一键插入草稿（不会自动发送）；在搜索框里输入「积分」「以旧换新」并回车，可看到无结果时不给结论、改为扩大范围 / 建缺口任务的守卫行为。
  6. 知识中心改为单栏查阅布局：检索范围压缩成筛选行下方的一行小字（明细收进「查看过滤明细」），不再有并列卡片抢版面；知识缺口汇总移到知识管理页（含影响会话量与建议动作），知识中心只留一行跳转说明。
  7. 知识管理列表按 Notice / Knowledge / 商品信息 三类分类展示（Tab 带各类条数，点击即过滤，可直接点着看）；发布前校验里的「发布设置」可选适用渠道（抖音小店 / 天猫旗舰店 / 微信小店 / 官网商城 / 门店 / 全渠道）与可见用户组（一线坐席 / 班组长·主管 / 知识运营 / 审批人 / 质检 / 数据分析）。
  8. 知识 / 公告的更新通知已从坐席工作台移出，集中在知识管理（知识库）顶部的「知识更新通知」折叠细条里：按适用渠道 + 用户组分发，展开可见变更内容、类型（已生效 / 版本更新 / 需处理）、生效期与操作。
  9. 知识管理与配置中心做了信息层级整理：每屏只有一个主区域（知识列表 / 意图阈值 / 当前生效版本 / 编辑与发布），指标压成一行细条，缺口明细、操作审计、变更记录收进可展开的细条；次要卡片用浅底并排——不再是一堆等大卡片。
  10. 配置中心改成「配置项 + 编辑与发布」两段式：左侧意图与阈值（阈值可直接改、每行可启用 / 复制 / 删除）、转人工触发条件、展示与生效规则都是可编辑配置项，改动标记「已改动」；右侧唯一的「编辑与发布」模块里集中放着待发布变更清单、影响提示、生效审批与发布 / 保存草稿 / 放弃改动。
  11. AI 策略按对象拆成两组：IQ 机器人 与 人工坐席助手，每组各有一套「Prompt 内容 + 安全与降级策略」——业务可调的只有这两类，模型 / 索引 / 工作流版本在右侧以「平台侧 · 只读」呈现，评测与变更记录收成折叠细条，发布门槛作为提示块放进灰度发布里。
  12. 转接状态 / 目标队列 / 排队情况 / 上下文完整度 / 幂等键等运营字段不在坐席侧露出（在 IQ 交接摘要页按权限查看），对话区也不再出现转接卡片，只保留一行系统事件。
  13. 交付研发时请剥离 data-comp / data-target 与 prd-highlight 脚本，详见 README。
