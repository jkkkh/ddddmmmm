功能概览
配置-01：意图阈值、转接策略与展示规则
  • 版本条：展示当前生效版本、未发布草稿项，并提供版本历史、回滚与草稿对比入口
  • 编辑模式提示：页面顶部一行说明「左侧为可编辑配置项，改动先进入草稿、不会立即生效」，明确编辑与发布的先后关系
  • 页面层级：左侧是配置项工作区（意图与阈值为主区域，转人工触发条件与展示规则为浅底次级卡并排），右侧是「编辑与发布」管理模块；操作审计收成可展开细条，不做等权重卡片堆叠
  • 配置项 · 意图与阈值：以可编辑表格呈现，置信阈值是输入框、启用是开关、每行提供复制 / 删除；卡头显示已改动项数并提供「新增意图」，卡底提供「还原本组」
  • 阈值口径：明确阈值为校准后的数值，不直接使用模型自报分数
  • 高风险意图：风险级别为高的意图不生成业务答案，直接转人工，使用警示色标注
  • 配置项 · 转人工触发条件：逐条可编辑（开关 + 数值输入 + 新增条件 + 已改动标记），顾客要求人工、连续未命中、高风险意图、知识冲突、接口失败等条件各自独立生效
  • 配置项 · 展示与生效规则：配置公告优先级、知识默认有效期与窄屏默认折叠辅助面板等展示行为，可新增规则
  • 「编辑与发布」管理模块：把发布动作集中在这里——待发布变更清单（可定位到对应配置项）、影响提示、生效与审批信息、以及「放弃改动 / 保存草稿 / 发布变更」
  • 影响提示（管理模块内的提示内容）：以警示块随变更清单一起展示，说明调参可能带来的业务影响与建议观察指标，不单独占一张卡片
  • 二次确认：高权限操作发布前弹出确认提示，并记录操作人、时间与变更内容
  • 操作审计：以可展开细条展示发布、审批与回滚记录，可追溯到具体版本

功能概览
配置-02：AI 质量策略、评测与灰度
  • 业务可调范围：明确 AI 策略中业务可调整的只有 Prompt 内容 与 安全 / 降级策略；模型、索引与工作流版本归属平台侧，只读展示
  • 按对象分区：配置项按 IQ 机器人 与 人工坐席助手 两组分别呈现，两组各有一套 Prompt 与安全降级策略，避免把两类 AI 的约束混在一起
  • 页面层级：左侧为业务可调配置区（IQ / 坐席两组，每组「Prompt 主区域 + 安全降级策略次级卡」并排），右侧为平台侧（版本只读、灰度发布主区域、评测与变更记录折叠细条）
  • IQ · Prompt 内容：以文本域编辑对客话术规范（语气 / 必须包含 / 禁止表达 / 证据不足时的处理），并提供澄清话术、转接话术、禁用表达清单等可调项；卡头显示改动状态与还原，卡底可保存草稿、对比已发布版本
  • IQ · 安全与降级策略：以开关配置「生成业务答案需通过 Answer Gate」「检索无结果 / 知识冲突时不作答」「高风险意图直接转人工」，以及 AI 故障时的降级行为（降级为检索 + 转人工）
  • 坐席助手 · Prompt 内容：编辑草稿生成规范（风格、必须带引用、禁止替坐席承诺、依据不足时的返回），并提供可选语气（更简洁 / 更有同理心 / 更清晰 / 更正式）
  • 坐席助手 · 安全与降级策略：配置「草稿只写入不自动发送」「依据不足返回 partial / insufficient」「润色需做事实一致性校验」「AI 故障时保留手工回复与知识检索」
  • 平台侧 · 当前生效版本：只读展示意图模型、Prompt 包、草稿模型、知识索引与工作流版本，业务侧不可编辑
  • 评测与回归（折叠细条）：默认收起为一行摘要（通过率 + 未达标项数），展开可见评测集、安全测试、未达标项与回归对比
  • 灰度发布：展示目标版本、灰度范围与进度，并提供「暂停灰度」与「回滚」；回滚为高影响操作，点击后先确认再执行并记录审计
  • 发布门槛（灰度模块内的提示内容）：以警示块列出安全测试、错误答案率与回滚演练等上线阻断条件及当前达成情况，不单独占卡片
  • 变更记录（折叠细条）：展示版本提交、灰度与索引重建等时间线，便于回溯
