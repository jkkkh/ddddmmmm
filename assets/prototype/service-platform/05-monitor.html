功能概览
监控-01：首屏看板
  • 时间与范围筛选：支持今日 / 近 7 天 / 近 30 天与渠道、市场筛选，并标注口径版本与刷新时间
  • 业务概况分组：展示今日会话量与 IQ 承接量、排队量、平均首次响应、平均处理时长、重复进线率、满意度、投诉与人效
  • 指标卡片：每张卡展示指标名、当前值、环比趋势与关键注解（如观察窗口、目标值）
  • IQ 表现分组：展示承接率、有效自动解决率、转人工率、无答案率、异常退出率与错误答案率
  • 口径说明：明确承接率与解决率口径不同、解决率不把「顾客停止回复」计为已解决
  • 坐席 AI 分组：展示草稿生成量、采用率、修改率 / 放弃率、摘要生成与修订率、处理时长变化与负反馈 Top 原因
  • 知识质量分组：展示检索次数、无结果率、过期 / 撤回命中、冲突命中告警、索引同步失败与负反馈知识 Top3
  • 过期命中与冲突告警：过期 / 撤回命中目标趋近 0 并使用警示色，异常可直接跳转到对应知识或任务
  • 技术运行分组：展示各环节 P50 / P95 / P99 延迟、接口成功率、业务拒绝与超时区分、工作流失败数与降级状态
  • 趋势图：按天展示会话量与自动解决率趋势，可切换指标
  • 下钻路径：任意指标均可按时间、渠道、意图、队列、知识类型 / ID、商品类目、模型版本与工作流版本下钻；个人绩效数据受权限控制
  • 查询性能：看板数据异步加载与分页，避免阻塞坐席作业

功能概览
监控-02：优化任务中心
  • 任务来源：无结果搜索、坐席人工修改、转人工、工作流失败与顾客负反馈自动聚合为候选任务
  • 状态筛选：按 NEW / TRIAGED / IN_PROGRESS / READY_FOR_TEST / RELEASED / EVALUATED 与终态 REJECTED、DUPLICATE 筛选，并支持按影响会话量排序
  • 任务列表：每行展示任务标题与编号、问题类型、影响会话量、状态、负责人与截止日；当前选中行高亮
  • 任务详情卡：展示问题类型、影响会话量、脱敏示例会话、疑似原因、建议动作、负责人、截止日、变更版本与上线时间
  • 「查看示例会话」入口：需要会话明细权限，敏感字段按权限脱敏
  • 上线前后对比卡：展示变更前后关键指标、结果评估与回滚链接，形成可验证的闭环
  • 自动化边界说明：自动诊断只产出疑似原因与候选动作，不允许未经审批自动发布知识或改配置
  • 任务转派：支持转派与改期，所有变更留痕
