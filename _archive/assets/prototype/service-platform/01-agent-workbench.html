工作台-01：主页面 · AI 助手面板
  • 会话队列区：三栏布局最左列，展示待接入 / 我的 / 待处理分组与排队会话列表，点击任一条即切换当前会话
  • 队列搜索框：支持按顾客 ID、订单号、会话 ID 或关键词检索；无权限的内容不出现在结果里
  • 队列分组 Tab：展示「待接入 / 我的 / 待处理」，右侧显示条数；切换分组只影响列表，不改变当前打开的会话
  • 会话卡：展示顾客显示名与脱敏 ID、最后一条消息摘要、渠道、等待时长、未读数与意图标签；超出队列承诺时长的会话卡左侧显示橙色提示条（明显但不阻断操作）
  • 不在对话区推送知识更新：知识 / 公告的更新提醒不在坐席工作台出现，避免打断接待节奏；更新通知统一在知识管理（知识库）的「知识更新通知」中查阅
  • 消息时间线：区分顾客、坐席、IQ 与系统事件；IQ 答复带「标准知识答复」标签与知识 ID / 版本引用，点击引用可查看原文
  • 工作流进度卡：展示流程名、版本、当前节点与已完成节点；只暴露业务节点状态，不展示内部提示词或隐藏推理
  • 上下文实体 Chip：识别到订单 / 商品 / 会员实体时在会话头部展示小 Chip，点击后在右侧面板打开对应详情
  • 右侧四模块面板：固定「会话摘要 / 知识搜索 / AI 助手 / 顾客·订单」四个模块按钮，同一时间只展示一个模块的内容，点击按钮即联动替换，不把多个模块内容堆在同一段滚动区；可折叠，切换会话时保留当前模块并重新加载该会话内容
  • 模块联动入口：输入区「搜知识」打开知识搜索模块、「AI 回复 / 重新生成」打开 AI 助手模块、点击会话头部的订单 / 商品 / 会员实体 Chip 打开顾客·订单模块；转人工 / 升级表单作为面板级临时动作区，展开时不改变当前模块
  • 会话摘要卡：面向「让坐席 3 秒抓住顾客诉求」组织信息，自上而下依次为结论式诉求、情绪与期望、关键事实、已答复内容、仍缺什么、顾客原话要点；支持复制与人工修订（修订后以人工版本为准）
  • 时间范围切换：卡头下方提供「过去 48 小时 / 过去 7 天」切换，默认 48 小时。48 小时看当前处理窗口内已确认的事实与答复；7 天看跨会话的重复进线、诉求演变与历史答复，避免坐席重复解释。切换只改变摘要取数范围，不改变当前会话与消息时间线
  • 范围说明行：展示本次摘要覆盖的消息条数与会话数、数据来源（会话消息 + 订单 / 售后记录）与生成时间，便于坐席判断可信度
  • 结论式诉求：首行用一句话概括顾客要什么、卡在哪儿（如「认为实收颜色与商品图不符，要求退货并希望今天内处理」），不写流水账
  • 情绪与期望标签：用徽标展示情绪状态、期望答复时效与进线次数，帮助坐席决定沟通语气与优先级
  • 关键事实行：只保留与当前诉求直接相关的事实（订单、签收时间、SKU），并标注来源时间
  • 顾客原话要点：按时间列出 2–3 条顾客关键原话（含时间戳），让坐席无需回滚长消息就能读到顾客的真实表达
  • 不展示转接状态相关内容：转接状态、转接原因、目标队列、排队情况、上下文完整度、幂等键等运营内部字段不出现在坐席摘要中；坐席通过对话区一行系统事件感知转接事实，完整转接数据在 IQ 交接摘要页（按权限）查看
  • 对话区可读性约束：会话头部控制在 1–2 行（超出省略），消息气泡限制单行阅读宽度（约 40 个汉字）并保留气泡间距，长文本不贴边换行
  • 不设「识别信息」模块：意图、实体与工作流状态不在辅助面板单独占卡片——队列卡提供意图导航标签、会话头部提供订单 / 商品 / 会员实体 Chip、对话区提供工作流进度卡；「纠正意图」作为轻量反馈入口收进输入区「更多」菜单，不占用坐席理解顾客诉求的面板空间
  • 建议动作卡：最多展示 3 条下一步建议并说明触发原因，高风险动作单独标注「需人工判断」
  • 回复草稿卡：展示草稿状态（依据充分 / 部分依据 / 依据不足 / 已阻断 / 生成失败）、正文与编号引用来源列表（标题、版本、生效日期、适用渠道）
  • 「插入输入框」按钮：展示主按钮（应用 .btn-primary 风格），点击后把草稿直接写入输入框——输入框为空时填入，已有内容时在光标处插入（不弹窗、不询问替换 / 追加，也不额外添加状态标记）；插入动作本身不会发送消息
  • 「重新生成」按钮：展示幽灵按钮（应用 .btn-ghost 风格），可选更简洁 / 更有同理心 / 更清晰 / 更正式；语气调整不改变事实与承诺
  • 「不采纳」按钮：展示幽灵按钮，点击后选择原因（不相关 / 事实不准 / 语气不合适 / 依据不足 / 重复 / 其他），反馈进入质量评测队列
  • 输入区快捷操作：仅展示 4 个高频按钮「搜知识 / AI 回复 / 润色 / 更多」，其余收进「更多」菜单；输入框为空时「润色」不可用
  • 回复输入框：支持多行与粘贴，Enter 发送、Shift + Enter 换行；草稿按「会话 + 坐席」保存到服务端，切换会话不丢失
  • 「发送」按钮：文本非空且会话可回复时启用；发送过程中显示发送中状态并禁止重复点击，避免顾客收到重复消息
  • 不设草稿状态标记：插入后输入框只呈现文本本身，不再叠加「AI 草稿 · 未发送」徽标；是否发送完全由坐席点「发送」决定，避免在输入区增加额外噪音
  • 面板折叠按钮：点击折叠右侧智能辅助面板，让对话区更宽；折叠状态在当前浏览器会话内记忆
  • 「转人工 / 升级」按钮：明确的业务动作按钮，点击后在右侧面板内联展开原因、目标队列、优先级与可编辑的交接摘要（见 工作台-04），全程不遮挡对话区
  • 无模态弹窗原则：本页面不使用阻塞式对话框。插入草稿处理、润色预览与转人工确认都在输入区或右侧面板内联展开，遮罩层为 0；反馈类提示使用非阻断的轻提示，坐席可继续阅读消息与输入
  • 辅助面板知识 / 顾客·订单 Tab：本 section 保留精简态便于点击演示，完整态见 工作台-02 与 工作台-03
  • 异常态处理：知识无结果时展示「未找到有效知识」并给出扩大范围 / 创建缺口任务入口；发送状态未知时先确认是否送达，再允许重试

  • 筛选条件：支持知识类型、市场 / 品牌、渠道、语言、是否生效与更新时间；默认过滤无权限、已撤回与失效内容

  • 检索结果列表：按相关性排序展示，结果卡必须包含标题、类型、摘要（含关键词高亮）、适用范围、更新时间 / 版本、来源系统与状态标签
  • 结果卡 · 已生效知识：展示绿色「已生效」徽标、知识 ID 与版本、更新日期、适用渠道，并提供「查看原文 / 插入知识片段 / 复制内部链接」
  • 结果卡 · 审核中版本：橙色「待审核新版」徽标提示当前生效版本可用于答复、新版本尚未生效；可查看版本差异，避免坐席引用未放行内容
  • 「查看原文」操作：在面板内或弹窗中打开完整内容，不丢失当前 Chat 状态
  • 「插入知识片段」操作：把选中的标准文本插入输入框，不自动发送，插入后仍显示「未发送」标记
  • 结果反馈：提供相关 / 不相关 / 已过期 / 内容有误 / 信息缺失五类轻量反馈，提交时自动附带查询词、知识 ID 与版本
  • 无结果处理：检索无命中时展示「未找到有效知识」，提供「扩大搜索范围」与「创建知识缺口任务」入口，不用通用模型答案替代
