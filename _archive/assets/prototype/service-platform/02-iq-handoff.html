功能概览
IQ-01：IQ 会话回放与放行审计
  • 会话头：展示顾客、渠道、承接方式、当前状态与关键版本信息（IQ 版本、意图模型与 Prompt 版本、工作流版本、开始与转人工时间）
  • 「导出回放」按钮：展示幽灵按钮（应用 .btn-ghost 风格），需权限校验并记录审计；默认不提供整段会话一键外发
  • 对话回放：按时间顺序展示顾客消息与 IQ 答复；IQ 答复标注「标准知识答复」并展示知识 / 模板 ID 与版本，点击可查看原文
  • 每轮内部决策卡：展示路由建议、结构校验结果、意图与已校准置信度、缺失槽位、风险标记与放行来源，供质检与排障对照
  • 「只看对客内容」切换：隐藏内部决策卡，只保留顾客可见的消息，便于核对顾客实际看到的内容
  • 答案放行审计卡：逐条列出每轮答复的合规来源（已生效 FAQ / Notice / 标准话术 / 工作流模板 / 校验通过的 API 数据）与版本，明确不存在无来源答复
  • 识别与路由明细：展示结构校验、置信度、澄清次数、工作流节点链路与响应耗时
  • 风险与兜底卡：展示风险意图、事实边界（是否做了承诺）与兜底动作；高风险场景不允许 IQ 自行安抚或承诺
  • 命中规则卡：列出本次命中的转人工条件、未命中的条件以及配置来源版本，方便运营核对规则效果
  • 检索失败 / 冲突 / 过期态：命中冲突知识、知识已过期或权限不足时，本页明确标注「未放行」及原因，不允许模型补充事实答案

功能概览
IQ-02：转人工交接摘要
  • 转接摘要卡：固定字段展示顾客诉求、已识别意图、关联订单 / SKU、已收集字段、已回答内容、已尝试流程节点、未解决原因、接口异常与风险标记
  • 生成时间：标注生成时间与时区，跨市场业务不默认服务器本地时区
  • 已引用知识与模板卡：列出本次对话引用过的模板与知识 ID / 版本，支持查看原文与版本，供坐席核对依据
  • 「打开会话回放」入口：跳转到 IQ 会话回放，查看每一轮决策与放行来源
  • 转接信息卡：展示转接原因、来源模块、目标队列与排队情况、优先级与幂等键
  • 建议下一步卡：给出 1–3 条建议动作并标注高风险动作需人工判断；建议不作为事实结论
  • 质量提示卡：展示上下文完整性、可追溯性与合规提醒（如不得承诺赔付或在会话内承诺政策例外）
  • 无人工队列时：展示留言 / 回呼说明与预计服务信息，并创建待办、保存上下文；不展示虚构的等待时间
