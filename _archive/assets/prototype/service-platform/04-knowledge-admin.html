功能概览
知识管理-01：知识列表
  • 页面层级：一屏一个主区域——知识列表；其余信息降级为细条或可展开细条（指标条 44px、缺口条默认 42px），不做等权重卡片堆叠
  • 知识更新通知（折叠细条）：知识 / 公告的更新提醒集中在这里（坐席工作台不再推送）。默认收起为一行摘要（通知条数 + 最新一条），展开后按行展示变更内容、类型（已生效 / 版本更新 / 需处理）、适用渠道与用户组、生效期、时间与操作（查看 / 对比版本 / 重试同步）
  • 通知分发口径：按「适用渠道 + 用户组」分发，只发给有权限查阅的人；支持订阅设置与全部标记已读
  • 指标条：压缩成一行（值 + 标签 + 注解，用分隔线区分），展示已发布 / 待审核 / 索引同步失败 / 30 天内失效；失败与待审核使用警示色，不再各占一张卡片
  • 知识缺口汇总（折叠细条）：知识缺口的集中呈现位置（知识中心不再展开）。默认收起为一行摘要（缺口数量 + 最高影响会话量与主题），展开后展示缺口主题与来源、近 7 天搜索次数 / 无结果次数、影响会话量、建议动作与操作
  • 缺口操作：支持「创建知识 / 指派负责人 / 转为待确认 / 打开被反馈知识 / 建优化任务」与批量指派；缺口候选来自无结果搜索与低反馈知识，正式新建知识仍需审核通过后才进入生产检索
  • 工具栏：提供知识 ID / 标题 / 负责人搜索、类型与状态筛选、市场与更新范围筛选，以及导出、批量审核与上传入口
  • 「上传 / 同步知识」按钮：展示主按钮（应用 .btn-primary 风格），点击进入上传与解析流程
  • 分类视图：按 Notice / Knowledge / 商品信息三类切换展示，Tab 上显示各类数量（全部 1,284 · Notice 128 · Knowledge 964 · 商品信息 192），切换即过滤下方列表并更新计数文案
  • 分类口径：Notice 为对外时效公告；Knowledge 为 FAQ、SOP、话术模板、门店知识等运营知识；商品信息为商品 / SPU / SKU 辅助知识，跟随商品数据版本、不单独设置有效期
  • 知识列表：每行展示知识标题与 ID（含适用渠道 / 用户组摘要）、分类与类型明细、内容状态、版本、有效期、索引同步状态、负责人与操作
  • 内容状态徽标：按状态机展示草稿 / 解析中 / 质检 / 待审核 / 已发布 / 已驳回 / 发布失败 / 已失效 / 已撤回，配色与语义一致
  • 索引同步列：与内容状态分开呈现（未入索引 / 已同步 / 同步失败），同步失败可重试并产生告警，避免「已发布但检索不到」
  • 待审核行高亮：待审核内容整行使用浅色底提示，行内直接提供「审核发布」入口
  • 行内操作：编辑、撤回、查看版本、对比版本、重试同步、指派负责人；撤回与发布操作记录审计
  • 缺口任务生成的草稿：来源标注为知识缺口任务，负责人未指派时可一键指派

知识管理-02：上传、解析与字段映射
  • 上传区：支持拖拽与选择文件，明确支持的格式、单文件大小与批量数量上限；另提供「从数据源同步」入口

知识管理-03：发布前校验与审批
  • 呈现方式：发布前校验以子页形式替换主区内容，不使用弹窗或遮罩；可随时「取消并返回知识库」回到列表
  • 页面层级：左列「发布设置」为主操作区（主色描边 + 浅色卡头，宽度约占 6 成），右列「发布前校验」为浅底次级卡片（紧凑行）；底部操作条左对齐主按钮「立即发布」，取消入口靠右
  • 校验清单：发布前自动检查必填字段、有效期、适用范围、内容冲突与审批权限，并逐项给出结论（通过 / 待确认 / 阻断）
  • 适用范围变化提示：与上一版本不一致时提示差异，避免公告悄无声息地扩大了适用范围
  • 冲突提示：与生效知识存在条件或口径差异时提示需审批人确认，不允许自动发布覆盖
  • 审批权限校验：显示本次发布对应的审批人与知识域，权限不足时明确说明需要的权限类型
  • 适用渠道：多选渠道（抖音小店 / 天猫旗舰店 / 微信小店 / 官网商城 / 门店 / 全渠道），决定哪些渠道的 IQ 与坐席可检索到该知识；与上一版本不一致时在顶部校验清单提示差异
  • 可见用户组：多选用户组（一线坐席 / 班组长·主管 / 知识运营 / 业务知识审批人 / 质检 / 数据分析），默认继承知识域权限边界；取消只缩小可见范围，不会自动放开给未勾选角色
  • 发布设置卡：集中展示适用渠道、可见用户组、计划生效时间（含明确时区）与审批人，避免跨市场误读与越权发布
  • 职责分离说明：编辑与发布权限可分离；无发布权限时「立即发布」禁用，仅可提交审批人
  • 「提交给审批人」按钮：展示次按钮（应用 .btn-secondary 风格），提交后内容状态变为待审核
  • 「立即发布」按钮：展示主按钮（应用 .btn-primary 风格），权限不足时禁用；发布成功后展示发布状态与索引同步状态两个结果
  • 审计：发布、撤回与版本变更均记录操作人与时间
